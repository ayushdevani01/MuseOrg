---
name: github-delivery
description: Deliver a change through checked PR, merge and deployment.
---

Use the trusted project delivery tools for protected remote operations. Repository
write credentials belong in the backend connection, never shell environment,
shared files or browser profiles. This skill grants no account or merge authority.

Read the connected repository state and exact base/head. Prepare a small allowed
patch or immutable file bundle from the coworker's working tree. Preserve tests
and policies; changes to workflow/security files need their own explicit scope.

Create the branch/PR through the connected provider and record its returned URL
and head SHA. Read real checks and reviews for that exact head. A queued, missing,
failed or superseded check cannot count as passing. Address failures through a new
reviewable commit and repeat verification.

Merge only through an unexpired grant or exact approval for this repository,
change and expected head. A moved head invalidates the merge intent. Respect
repository rules and review requirements.

Follow the real deployment for the merged revision. Verify the live HTTP behavior,
reported revision and an important browser interaction. Keep pending or uncertain
outcomes visible; reconcile before retrying a write. Report linked receipts rather
than inferring success from a tool call or a merge alone.
