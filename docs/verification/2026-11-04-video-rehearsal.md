## Media and handoff

The employee transcribed the supplied synthetic MP4 through native audio
normalization and read its saved transcript. An initial segmentation attempt
failed after descriptive text was mixed with an encoded selection. It remains
recorded as failed work, and was not counted as a successful media receipt.

The segmentation tool now accepts typed source-pixel box coordinates. The Meta
adapter uses the official parser's builder to format them, validates bounds and
rejects mixed legacy input before dispatch. The corrected employee run produced
a real transparent cutout and an English image. A later run created the Hindi
variant and sent the actual shared paths to the growth employee. That peer read
the transcript and produced six local platform/language draft entries.

Independent checks verified completed media receipts, RGBA transparency, both
image-edit source hashes against the saved cutout, real image paths and the draft
file's structured contract. Generated copy and visuals remain review candidates;
these assertions do not grade language quality. A copy correction removed an
unapproved benefit claim from the draft brief.
